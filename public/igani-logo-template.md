# Igani Logo Template

## Required Specifications

### File Format
- **Preferred**: PNG with transparent background
- **Alternative**: SVG for scalability

### Dimensions
- **Width**: 150px
- **Height**: 60px
- **Aspect Ratio**: 2.5:1 (width:height)
- **Resolution**: 72-96 DPI (web standard)

### File Naming
Please save your logo as one of these names:
- `igani-logo.png` (preferred)
- `igani-logo.svg` (alternative)

### Design Guidelines
- Use a transparent background
- Keep the design simple and recognizable at small sizes
- Ensure good contrast if logo will appear on light backgrounds
- Consider a monochrome or subtle color version for watermarking

### Placement
The logo will be used as a subtle watermark in:
- Footer sections
- Bottom-right corners of main content areas
- "Powered by" sections

Once you upload your logo with the correct filename, it will automatically appear across the website.
